# W2 원문 탐색·선택 자료 재사용

현재 채팅의 수동 WEB 지원 구현이며, 실제 팀원의 직접 작업으로 기록하지 않는다.

원문을 유형·페이지 모델·게시일 확인 여부·기간·키워드로 필터링한다. 기간은 date_kind=posting이고 유효한 published_at이 있는 자료만 대상으로 하며 날짜 미상은 별도 선택한다. 구매일은 확인된 source.metadata.purchase_date를 별도로 표시하며 게시일로 변환하지 않는다. 실제 DATA의 metadata 구조를 읽어 purchase_date 필드가 있음을 확인했다.

등록된 주제 어휘 확장(소음/시끄럽/시끄러/조용, 냄새/악취)은 규칙 검색이다. LG가 승인한 사전 또는 실모델 의미 검색이라고 주장하지 않으며 이번 검색에서 추가한 어휘를 표시한다. 단어 사이에는 AND, 같은 확장 그룹 안에서는 OR를 적용한다. 긍정 표현을 불편으로 분류하는 기능이 아니다.

선택 원문은 전체 source 객체와 facts를 그대로 복사한 ResearchBundle JSON과 Markdown으로 내보낸다. 원 bundle ID·SHA256, 선택 source ID·내용 지문·후기/사실 수정0·독립평가 승인false·서버 부분 자료 기획 지원false를 manifest에 기록한다. 서버 SHA가 없으면 브라우저 canonical JSON으로 계산했음을 명시한다. 선택 파일을 만들더라도 현재 기획의 입력 bundle이나 실행 결과를 바꾸지 않는다. 필터 밖에 남은 선택도 개수를 표시한다.

수집 manifest의 원기록을 보존하고, 현재 필드에서 확인되는 임의 표본·게시일/구매 SKU 미상·평가 승인 상태·문서 발췌·부분 자료 선택·Q&A 누락을 한국어로 먼저 표시한다. POST 기획 실행이 비활성화된 경우에는 자료 조회 연결과 모델 활성화 대기를 구분하며 원문 탐색을 계속 사용할 수 있다.

React 검토에는 vercel:react-best-practices를 적용했다. 별도 원문 패널로 상태를 한곳에 두고 원문/필터 변경만 메모한 결과를 사용한다. 체크박스·필터에 접근 가능한 이름을 주고 선택 내보내기 중 중복 클릭·화면 이동 후 지연 파일 다운로드를 막는다. 새 API 호출·localStorage·모델 호출은 추가하지 않았다.

구조 검사는 이미 저장된 공개 후기와 실제 MW23FDI 설명서 25쪽의 출력 조절 원문/facts/locator를 사용한다. 일부 날짜 메타데이터는 형식 검사용이며 실제 후기 게시일로 주장하지 않는다. 실모델 의미 검색·기획 품질 검증을 뜻하지 않는다.

W2 신규8개와 새 W1 흐름5개, 총13개 검사가 통과했다. 실제 모델이 비활성인 POST 오류 뒤에도 원문이 유지되는 DOM 검사를 포함한다. TypeScript와 production build도 통과했다. 기존 전체 검사나 모델 실험을 반복하지 않았다.
