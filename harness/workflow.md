# 현재 실행 절차

최신 기준은 [AtoZ_사용법.md](AtoZ_사용법.md)와 `atoz.json`이다. 현재 Codex가 단계별 일을 실제로 수행하며 `ax_workflow.py`가 의존성·증빙·재개를 연결한다.

1. 최신 자연어 요청과 `AGENTS.md`를 읽는다. 상태 질문·의논 요청은 작업 실행으로 바꾸지 않는다.
2. `python scripts/ax_workflow.py next`로 다음 가능한 작업과 필요한 입력을 확인한다.
3. 도구로 조사·분석·생성·실행·검토하고 해당 단계 JSON 결과와 증빙을 저장한다.
4. `finish <stage> <artifact>` 후 `validate`한다. 변한 근거와 미확인을 기록한다.
5. 사용자가 지정한 범위 내에서 다음 단계로 이어간다. 개인정보·서명·권한이 필요한 단계만 실제 필요에 따라 확인한다.
