# KITCHEN AX v22 · 역할별 동작과 현재 작업

공개 Site 버전24과 동일한 UI 구현입니다. PR 검사에서 테스트 파일의 행 끝 공백1개만 정리했습니다. 소스 커밋: `36bb74f96741f163a97c4393edfe6493f2ab9f85`.

- 길은 기존 연결 구조를 유지하며 작업실·연구원 뒤에 표시합니다.
- 여섯 Skill마다 문서 스캔·카드 묶기·제품 대조·모형 조립·원문 검사·웹 검색 동작이 다릅니다. 대기 시 승인한 착석 원본을 사용합니다.
- 초록 명판의 글자 크기·각도·높이를 맞추고, 단독·병렬 실행의 확대와 선택/실행 상태 분리를 보존합니다.
- 오른쪽 현재 작업과 왼쪽 접이식 Skill 목록을 추가했습니다. 좁은 창은 하단으로 배치하며 낮은 창에서는 접어 둡니다.
- 실제 연결 전에는 실행·처리 수를 만들지 않습니다. 기록 재생·모션 예시·실제 관측을 구분합니다. 실제 CLI 연결은 이 검증에서 수행하지 않았습니다. 합성 관측 파일을 기존 파일 선택 UI로 열어 표시 경로를 검사했습니다.

## 복원과 실행

이 폴더 [v22 소스](v22-20261017/)를 별도 폴더로 복사한 뒤 아래 순서로 실행합니다. 기존 버전 폴더를 덮어쓰지 않습니다.

```text
npm ci
npm run dev -- --host 127.0.0.1 --port 5177
```

모션 예시는 `?view=motion`에서 확인합니다. 실제 관측 연결은 [CLI 테스트 순서](v22-20261017.TESTING.md)와 릴리즈 읽기 서버를 이용합니다. 이 복원본은 실제 팀 하네스·데이터베이스를 실행하거나 팀 모드를 켜지 않습니다.
