# 버전 15 복원·실행

팀 저장소의 `대시보드 신진하/versions/v15-20261016`이 최신 대시보드의 독립 소스 폴더입니다. 이전 루트 버전 5는 바꾸지 않았습니다.

```powershell
git clone --branch codex/dashboard-shin-jinha-v15-20261016 https://github.com/2026-LG-kitchen-chicken-team/lg-ax-2026.git
cd "lg-ax-2026/대시보드 신진하/versions/v15-20261016"
npm ci
npm run dev
```

Node.js 22 이상을 사용합니다. 테스트는 `npm test`, 빌드는 `npm run build`입니다. Python 연결은 소스의 `docs/RELEASE-CONNECTION.md`를 따릅니다. 키나 개인 실행 DB는 포함하지 않았습니다. 브라우저에 저장했던 개인 조건·실행 기록은 소스 코드와 별개이며 같은 브라우저의 저장을 사용합니다.

원본은 하네스 저장소 커밋 `1c63408e4f7d5d5aa72fc4ffb227e5689b2e1923`의 추적 파일 그대로입니다. 공개 Site 버전 15와 대응하며 별도 Site 배포 식별자는 복사하지 않았습니다. 소스 안 `SOURCE-SNAPSHOT.json`은 하네스에 최초로 가져온 버전 10의 이력입니다. 이번 버전 15의 출처와 74개 파일 해시는 옆 `v15-20261016.manifest.json`이 정본입니다.

이 브랜치를 보관하면 이후 작업과 별개로 이 버전으로 돌아올 수 있습니다. 다른 작성자의 변경이나 보존 브랜치를 초기화하거나 강제 푸시하지 않습니다. 팀 제품 자동 연결·main 병합은 이 보존 작업에 포함하지 않습니다.
