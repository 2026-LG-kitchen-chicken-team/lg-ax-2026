# 공장 관제실 공동 작업

이 폴더는 사용자가 요청한 KITCHEN AX 공장 화면의 Git 개발 경로입니다. 저장소의 기존 관제실 경로를 확인하고 그 아래에 버전 10 원본을 보존했습니다. 저장소 루트와 `web/AGENTS.md`의 공통 지침을 따릅니다.

## 실행

```powershell
cd web/prototypes/control-room/factory-dashboard
npm ci
npm run dev
```

검사: `npm test` · 빌드: `npm run build`. Python 연결 방법은 `docs/RELEASE-CONNECTION.md`를 확인합니다. 실제 릴리즈 연결과 로컬 규칙 데모는 구분합니다. 화면에서 모션 미리보기를 열어도 CLI 업무나 모델 호출을 시작하지 않습니다.

## 브랜치와 보존

- 수정 전 원본은 `archive/kitchen-ax-factory-v10-20261016` 브랜치에 보존합니다. 이 브랜치를 계속 덮어쓰거나 force push하지 않습니다.
- 기능 수정은 별도 `feat/factory-zone-motion-20261016` 브랜치에서 진행합니다. 작업자는 각자의 checkout/브랜치를 사용하고 수정 파일·검사·제약을 PR에 기록합니다.
- 신진하·최길웅이 같은 파일을 수정해야 하면 PR에서 먼저 범위를 맞춥니다. 다른 작성자의 변경을 초기화하거나 main에 강제 반영하지 않습니다.
- 실제 실행 기록, 개인 경로·설정, 인증정보, SQLite, `node_modules`, 빌드 출력은 Git에 넣지 않습니다. 기존 합성 시연 자료는 합성 표시를 유지합니다.
- 이 폴더에 Sites 배포용 `.openai` 식별자는 복사하지 않았습니다. 기존 공개 Site의 배포는 별도로 관리하며 다른 저장소를 변경하지 않습니다.

## 이번 요청 범위

실행 공간의 진입 확대와 동시 실행 배치, 구역 안 연구원 순환 이동, 작은 뷰포트 대응, 화면 전체로 이어지는 타일 필드입니다. 실행·근거·데이터 계약은 유지합니다. 구역은 시각적 작업 장소이며 실제 위임이 없는 연구원을 독립 서브 에이전트로 표시하지 않습니다.
