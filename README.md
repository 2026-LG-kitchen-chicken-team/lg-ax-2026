# LG AX 해커톤 작업실

이 프로젝트는 **LG전자와 함께하는 국립창원대학교 AX 해커톤 대회**만 다룹니다. `공모전 계획`의 LG 관련 대화·공식 자료를 2026-09-27에 이관했습니다.

## 현재 상태

| 항목 | 상태 |
|---|---|
| 참가팀 | 정이량·신진하·최길웅, 국립창원대학교 학부 재학생 3명 |
| 주제 | **재검토 중**. 6개 후보 비교, B8 동시 조리 흐름·A8 공간 제약 기획 우선 검증. 최종 선정 전 |
| 내부 접수 목표 | **9/27 오늘 신청 완료**. 공식 마감과 별개인 사용자 목표 |
| 접수 마감 | **2026-09-28(월) 18:00, 한국시간** |
| 접수 서류 | 신청서·HWP 제안서 10쪽 이내·동의서·서약서 |
| 선발 후 핵심 | 작동하는 Agent·Skill 구현, 발표자료 20쪽 이내 |
| 준비 완료 | AtoZ 12단계 하네스. 최신 요청의 조사·6개 후보 비교 완료. 이전 코드 검사 43개 통과는 후보 성능 검증과 별개 |
| 아직 미확인 | 팀명·팀장·학년·학번·연락처·이메일·서명·접수 완료 여부 |
| 개발 환경 | [jeongiryang/lg-ax-2026](https://github.com/jeongiryang/lg-ax-2026) 비공개 저장소 연결. 최소 Skill만 실행, 참가작 Agent 미완성 |
| 구현 조건 | 핵심 시연은 PC에서 완결. 제안하는 가전·서비스는 웹으로 제한하지 않음. 모델 연결·UI·실사용 평가 미완료 |
