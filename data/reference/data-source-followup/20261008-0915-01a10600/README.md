## 구분해서 읽기

1. `manual-applicability.sidecar.json`/CSV는 문서와 모델의 관계, 선택 기능 미확인, 공식 설치 분기를 분리한다. 확인15개 지원 링크는 모든 기능의15모델 적용 승인과 다르다. 정확 모델 문자열의 native 검색 결과0도 기능 부재로 쓰지 않는다.
2. `usage-qa.sidecar.json`의 source_type은 FAQ, 작성 주체는 제조사다. 고객 후기·구매/재입고 문의를 사용 불편 분모에 넣지 않는다. 기사 표시일을 고객 게시일로 바꾸지 않는다.
3. `review-dates.sidecar.json`은 새 관측1건을 별도로 남긴다. 표시된 review date는 확정한 관측값이고, 확인된 최초 게시일 `published_at`·구매일은 `null`이다. 승인된 시간 분모 **0**, `ratio:null`. 기존238/개발141·PR258 주제 초안 **draft/unapproved** 유지.

원 고객 이름·이미지·후기 전문·전체 HTML/PDF를 재배포하지 않는다. 짧은 원구절과 해시·위치·원 링크만 전달한다. 원문 응답과 원PDF는 local/private에 있고 raw HTTP SHA와 browser DOM 본문 SHA는 다른 값이다. SSG 일반 HTTP는 거절됐지만 그 이전에 정상 공개 브라우저에서 읽은 관측은 별도로 보존했으며 로그인·숨은 API·접근 우회는 없다.
