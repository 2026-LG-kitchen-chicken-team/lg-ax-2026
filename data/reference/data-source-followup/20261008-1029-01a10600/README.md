# 기존 세 제품의 주장별 자료 계약 정리

이 단위는 새 원문/답변을 합성하지 않고 기존PR187/197 자료를 인수해 안전하게 사용할 수 있는 주장을 하나로 연결했다.

- 기존 선택/조건 기능10개: 확인5, 정확SKU 사양의X/불일치2, 미확인3.
- 기존 canonical9기능/21근거는 원ID·정확모델·판본·실제/합성구분·조건을 보존하고 연결했다. 접이식 선반의 존재 근거와 수량은 분리한다.
- 간편조리700/1000W는 기존 확인 상태를 유지한다. 이번에 MW23FDI 정확 공식지원 페이지에서 기존manual fileId 연결만 새로 확인했다. 전원분리 후 유지와 사용자 시간/출력 조합 저장·호출은null/미확인이다.
- 미확인3: 냉장고트레이 걸이 기본 동봉, 손잡이형 제빙구성 기본 동봉, 사용자 조합 저장/호출. 호환부품이나 미언급을출고확정/미지원으로 바꾸지 않는다. 확인질문을 남겼다.

자료 계약의분류·근거·질문 준비와 실제 제품답변/독립채점·PM승인은 별도다. 실제고객불편 해결값은null, 운영/Schema/CORE/WEB/공유README는무변경이다.
