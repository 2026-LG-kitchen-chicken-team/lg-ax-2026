# PM의 공개 설명서 자료 인수 · 2026-10-06

PM의 별도 작업 공간에서 담당자 PR 원본을 보존하고 자료 코드를 인수했다. 원본과 버전·해시는 `evals/pm-data-intake/20261006/source-intake.json`에 있다. 원본 담당자 기록이나 이전 평가 결과를 이번 PM 실행으로 바꾸지 않았다.

`generated/`는 공식 LG 설명서 3개를 실제 다운로드하고 승인된 SHA-256과 대조한 뒤 새로 등록한 자료팩이다. 버전은 `lg-manual-scope-20261006.3-pm-intake`, 공개 설명서 근거 21개와 기능 9개다. 이전 버전의 15개 근거에 담당자 PR #141의 누락 위치 6개를 추가했다. 각 위치의 PDF 원본 해시·페이지·문자 범위·원문 해시를 pypdf 6.10.0으로 다시 검사했다. 이번 실행에 OCR·모델·GPU 호출은 없다.

각 제품 폴더 `T876MEE1H1/`, `DUE6BGL2E/`, `MW23FDI/`에 `dataset.json`, `normal.input.json`, `changed.input.json`을 둔다. 두 입력은 같은 모델·문서 버전·원문을 사용하고 제외 조건만 바꾼다. 기획 요청은 가상 시나리오이며 `reviews=[]`다. 고객 불편이나 효과를 증명하는 실고객 자료가 없으므로 고객 요구 판단은 보류해야 한다. 혼합된 공개 설명서·합성 리뷰 계약을 새로 도입하지 않는다.

재생성은 승인된 인증 없는 DATA 검증 환경에서 다음 명령으로 실행한다. 출력 폴더가 이미 있으면 원본을 보호하기 위해 거부한다. `/artifacts/`의 새 하위 폴더처럼 쓰기 가능한 경로를 지정한다.

```text
python -B data/research/PM-DATA-intake-20261006/build_pack.py --output /artifacts/fresh-public-pack
```

선택적 PDF 파서는 `data/tools/pinned-pypdf/`의 검증된 휠만 사용한다. 활성 환경에 설치하지 않으며 네트워크·인증정보 없이 원본 PDF를 읽는다. `source-download.json`과 `parser-wheel.json`에 URL과 전체 해시가 있다. `source-range-verification.json`은 실제 텍스트 위치의 재현 증거이고 새로운 OCR·시각 배치·SKU별 기능 적용 확인을 뜻하지 않는다.

`pack-summary.json`의 조건을 소비자가 함께 읽어야 한다. 냉장고 옆 간격 5cm/10cm 상충을 평균내지 않았고, 식기세척기 치수의 빌트인/프리스탠딩 열 조건과 전자레인지 최대 고주파 출력/소비전력 및 설정 유지 미확인을 보존했다. 자료의 모델 연결은 기존 승인 계획을 계승하며 선택 기능의 개별 SKU 적용을 추가로 입증하지 않는다.

기존 합성 리뷰 CSV 36건의 원본은 그대로 보존했다. `synthetic-reviews-derived-wire.csv`는 명시적인 필드 순서 변환본이며 원본이 아니다. 같은 자료 ID를 공유하는 5개 모델은 각각 승인 범위로 나눠 새 CSV 가져오기 모듈을 실제 검사했다. 날짜·시각·리뷰 분류 열이 없으므로 월별·계절별 분석 대상은 0건이다. 제품군은 모델 ID로 기존 제품 표에 연결할 수 있다. 합성 자료를 실고객 근거로 표시하거나 날짜를 만들어 넣지 않았다.

이 인수는 자료 기능과 재현 입력의 검증이다. 고객 수요·모델 성능·전체 DATA Epic 완료·실제 Agent 반복 실행·전체 통합 완료는 후속 검수 대상이다.
