# [P2-DATA-001] 실모델 원문 계약·기획 입력·설명서 등록 연결 부분 인수

게시 초안이며 현재 push·PR 생성은 보류다. 후보 대상: 비공개 `2026-LG-kitchen-chicken-team/lg-ax-2026`의 `main` ← `codex/data001-stage123-20261005`. 이전 `7cc25fb` 자료 묶음과 최신 `6b9dbe9` 계획 입력 구현을 보존한 작업 공간이다. 최종 commit과 포함 파일은 로컬 전달 수신증에서 고정한다.

## 문제와 결과

기존 실제 LG 참고팩은 조회 가능한 canonical Evidence가 없었고 기본 DemoDataset은 합성 전용이라 실제 문서를 바로 넣을 수 없었다. 세 실모델의 공식 설명서에서 9개 사례 기능·10개 짧은 원문 근거를 별도 DocumentDataset으로 연결했다. 공통 Product/Feature/Evidence 규격과 기존 검색 함수를 재사용하면서 기본 합성 데이터 정책·공통 schema·lock·기존 API/MCP는 유지한다.

최신 `build_planning_input`으로 같은 모델·설명서 버전의 전체 정의 근거/기능을 포함한 세 입력을 생성했다. 최소 로컬 등록 경로에서 실제 PDF를 HTTP 업로드하고 pypdf 파싱·연결 검증·저장·검색·근거/원문 반환까지 실행했다. 공통 작업실 연결이나 실제 AI 판단을 성공한 것으로 표시하지 않는다.

- 이전 60항목·공식9/SSG3 참고팩과 실제 Product 3건 보존. 새 선택 계획·등록 결과·fact/근거/원문 위치 연결·세 모델 입력·실제 HTTP 증거·전용 문서 처리 코드와 회귀 검사 포함.
- 실제 HTTP 33요청/60검사 통과: 모델·근거 ID·문서 ID·페이지·버전·`public` 유지, 원본 hash 반환, 중복 등록, 종료 후 저장 유지, 다른 모델 PDF·버전·ID·인증/Origin 오류 차단.
- 회귀 382개·계약·규칙 동기화·phase2·기존 하네스·MCP stdio PASS. 신규 단위검사 8개 포함. 미커밋 시험 코드 hash를 최종 전달 commit과 별도 수신증으로 대조한다. 원격 CI·새 웹 build/e2e는 실행하지 않았다.
- 자기 기록 `신진하-20261005-002-local`·근거 `신진하-E008-local`와 실행 파일을 묶는다. 포함 목록은 `delivery-manifest.json`으로 고정한다.

## 제한과 후속

실제 고객 리뷰 0건이다. 제품 페이지/판매처를 설명서나 리뷰로 위장하지 않았다. 공용 설명서의 모델 적용 조건과 정의한 제출 사례 범위만 포함한다. 60항목 중 나머지 50은 원래 참고팩에서 보존한다. 출처 차이 2건·미확인 7건, 독립 평가의 PM 확인·실제 평가 미완료를 유지한다. 전체 LG 기능 목록이나 실제 고객 수요·효과를 입증하지 않는다.

R03 설명서 경로만 개별 검증했고 CSV/명세 등록·공통 작업실/API/MCP 통합은 아직이다. R04/R13 실제 리뷰 불편 원문 및 판단 출력 추적, R08 세 제품군 실제 AI 판단 완주, 독립 평가와 PM 인수/검수/병합/통합은 미완료다. #12/#13 전체를 종료하는 PR이 아니다.

가상 모델·합성 리뷰·비공개 평가 입력/답안의 새 원문은 이 PR에 추가하지 않는다. 원문 PDF·전체 추출·이미지·로컬 DB·토큰은 private에서 제외된다. 공식 URL과 최소 원문 근거만 전달한다.
