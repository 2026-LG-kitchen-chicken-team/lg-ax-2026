# 승인한 세 실모델 참고 자료팩

확인일: 2026-10-04 KST. 공식 핵심 자료 9건 + 동일 모델 SSG 판매글 3건, 사실 60항목. **이번 자료 정리 완료 / #12 전체 미완료**.

T876MEE1H1 냉장고(선반 청소·분리), DUE6BGL2E 식기세척기(식기 조합·적재), MW23FDI 전자레인지(반복 설정·저장/호출 확인)라는 사용자 승인 범위를 적용했다. 로봇청소기를 제외했고, 냉장고 여러 모델을 별개의 필수 제품군으로 계산하지 않았다.

## 파일과 사용법

- [reference-pack.json](reference-pack.json): 기존 Product의 모델·제품군·문서 버전·자료 성격 필드와 별도 사실/출처/미확인/충돌 목록.
- [facts.csv](facts.csv): 모델별 필수 정보. `model_id`로 필터하고 `status`·`conditions`를 함께 읽는다. 각 행에 출처 URL·확인 시각·문서 버전·페이지/섹션을 연결했다.
- [sources.csv](sources.csv): 공식 문서/판매글 12건의 URL·게시일·문서 개정·적용 범위·해시.
- [conflicts.csv](conflicts.csv): 두 출처의 관찰값을 모두 보존한 차이 2건.
- [verification.json](verification.json): 최소 확인 실제 결과와 파일/원본 PDF/보존 자료 해시. **PASS는 이 참고팩의 구조·연결 대조 범위**다.

CSV는 UTF-8 BOM 형식이라 기존 Excel 등에서 열 수 있다. 추가 설치는 필요 없다. `confirmed`는 확인한 사실, `conditional`은 적용 조건이 있는 값, `unconfirmed`는 미확인, `conflicting`은 서로 다른 관찰값이다. `public`은 공개 열람 자료라는 뜻이며 문서/이미지/후기 재배포 허가가 아니다.

공통 계약에는 웹 URL·확인 시각·미확인 상태 필드가 없으므로 사실과 출처를 별도 sidecar로 저장했다. **이 파일은 DemoDataset이 아니며, 합성 전용 기존 DemoStore에 직접 넣을 수 없다.** 새 검색·파서·UI·하네스를 구현하거나 공통 schema를 바꾸지 않았다.

확인 시각은 이번 수집 결과를 대조한 기록 시각이다. 원문 조회 구간도 sources에 표시했다. HTML의 `unversioned@2026-10-04`는 수집 표식이며 제조사 개정번호가 아니다. 페이지는 인쇄 페이지 기준이며 이번 확인 페이지는 1-based PDF 번호와 일치한다.

### CHECKPOINT 전달 시 파일 표현 정정

최초 Windows 생성본의 CRLF 줄바꿈을 저장소 .gitattributes 규칙인 LF로 맞췄다. JSON/CSV의 정보와 원본 PDF/기존 자료는 바뀌지 않았다. verification.json의 현재 출력 해시는 LF 파일 기준이며 원래 수집 당시 Windows 바이트 해시는 line_ending_normalization 이력으로 보존한다. R03·전체 #12 완료 상태는 그대로 미완료다.
