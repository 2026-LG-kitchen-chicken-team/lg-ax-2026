# [P2-DATA-001] 자료 등록·작업실 조회 연결과 검증 증거 부분 인수

기존 실제 자료팩은 공통 작업실의 합성 전용 기본 저장소에 연결되지 않았고, 리뷰 CSV 등록 증거도 없었다. 실제 세 모델의 등록된 설명서 자료를 전용 adapter로 기존 작업실 조회에 연결하고, 기존 합성 리뷰36개를 private CSV로 전송해 업로드·파싱·검증·조회·재시작 후 원문 연결을 확인했다. 기본 합성5모델/36리뷰/42근거와 공통 Schema·API/MCP·판단 코드는 보존한다.

## 인수 범위와 검증

- 기존 세 실모델 자료60항목/공식9·SSG3/차이2·미확인7, 사례 Product3/Feature9/Evidence10, 원문/버전/페이지/자료ID 연결과 같은 모델의 전체 정의 근거 입력을 함께 인수한다. LG 전체 기능/실제 고객 수요 자료가 아니다.
- 기존 설명서 PDF3건 HTTP33요청/60검사 증거를 보존한다. 새 리뷰 CSV·작업실 HTTP66요청/70검사는 모델/버전/public 또는 synthetic/행·페이지/ID와 원본 hash 유지, 인증·다른 모델·버전 차단, 재시작 유지 확인을 포함한다.
- 신규 경계 단위검사5개. 전체 회귀 결과는 `checks.json`의395개 최신 실행을 기준으로 한다. 최초 샌드박스 실패2개와 동일 코드의 사용자 환경 재실행 증거를 함께 남긴다. 원격 CI·웹 build·브라우저 E2E는 이번 변경에서 실행하지 않았다.
- 독립 평가6유형의 PM manifest 형식·실제 파일/hash·개발ID/동일문장 겹침0을 확인했다. 정답 타당성·의미상 독립성은 PM 검토 전 미확인이다. 모델 비교나 독립 평가를 실행했다고 표시하지 않는다.
- 자기 작업기록003-local·근거E009-local 및 명령/실패/검증 결과를 같은 commit에 포함한다. Git blob/hash와 최종 commit의 일치는 로컬 receipt로 고정한다.
- 최신 PM MINIMUM-HANDOFF에 맞춘 모델별 input/dataset 세 쌍과 같은 모델/버전의 전체 정의 근거 입력 대조 결과를 포함한다. 10/5 18:00 KST 최소 인수물/막힘 보고 요청을 확인했다. 비공개 평가 원본/기대 대응 ZIP13파일은 hash만 기록하고 PR/Issue에 원문을 넣지 않는다.

## 알려진 제한과 PM 확인 요청

실제 고객 리뷰0건이다. 기존 합성 CSV는 JSON에서 만든 전송용 자료로 과거 원본 회수나 실제 LG 고객 후기가 아니다. 원문/합성 리뷰/평가 답안·입력 전문·PDF/이미지/추출/DB/토큰은 새 PR에 넣지 않는다.

현 PC의 기존 모델 설정·서비스가 없어 세 요청의 실제 AI 호출은0건이다. HTTP201은 failed 실행 기록의 저장이며 판단 성공이 아니다. PM에게 기존 연결만 문의했고 새로운 연결·설치·유료API·GPU 점유 변경은 하지 않았다. 실제 출력의 리뷰/기능 추적과 세 제품군 판단 완주(R04/R05/R06/R08/R13)는 남았다.

R03는 승인한 PDF·기존 합성 CSV·자료 조회의 개별 연결 증거다. 일반 명세 JSON 업로드·OCR·임의 문서 지원/#13 전체 완료로 확대하지 않는다. 자료 계약의 인정 범위, 문서 adapter 소비자 적용, 평가 독립성/정답, 후속 실제 리뷰 사용 범위를 PM이 검토해야 한다. PM 검수·병합·통합·#12 전체 완료는 미확인이다.
