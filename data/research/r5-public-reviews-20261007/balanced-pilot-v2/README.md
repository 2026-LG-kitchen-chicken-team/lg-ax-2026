# 최신순·낮은 별점순 비교 연구 표본

PM 보조 AI가 사용자의 전체 작업 승인과 PM의 한정 배정에 따라 정상 LG 공개 UI에서 수집했다. DATA 신진하의 개인 실적이나 자동 Worker의 결과로 기록하지 않는다.

- 버전: `lg-public-reviews.20261007.r5-balanced-pilot.v2-research-held`.
- 기존 파일럿 T876MEE1H1, MW23FDI, DUE6BGL2E 각각 최신순 첫10행·별점 낮은순 첫10행, 총60행. 더 많은 페이지·다른 품목·숨긴 API를 수집하지 않았다.
- 원후기 ID60개 중 기존 v1과 겹치는860977 한 건은 원 split을 유지했다. 신규 ID59개이며 v1의179개와 합친 전체 고유 ID는238개다.
- 신규 분할: 개발36·독립평가10·시연11·격리2. 격리는 화면과 행 MD가 다른861640 및 본문 연락처·업체명을 생략한457803이다.
- 전체238개의 개발·독립평가·시연 간 원 ID, 정규화 본문 그룹 ID, 정규화 본문 SHA의 세 쌍 교집합은 모두0이다. 기존 파일·분할·설명서 세 판을 수정하지 않았다.
- 최신순30행은 별점5, 낮은순30행은 별점1점22·2점2·3점6이다. 선택 표본이므로 불편 발생률·시장 수요·전체 고객 대표성을 추정하지 않는다. 별점과 본문 감정을 동일시하지 않는다.
- 작성일과 실제 구매 SKU는 모두 미확인이다. 화면 MD·후기 행 MD는 페이지 연관 정보로만 보존한다. 표시 날짜는 구매일이며 게시 시점을 뜻하지 않는다.
- 현재 제품 설명서 세 판은 참조만 유지했다. 실제 구매 당시 설명서판과의 일치는 검증되지 않았다.
- 모든 행은 연구용이며 `eligible_for_model_input=false`다. 제품별 기획 생성·실제 모델 평가·시연 입력으로 사용하지 않는다. 모델 호출·DB 생성·외부 게시0.

`records.json`은60개 ID의 관찰 결과, `new_unique_records.json`은 v1과 겹치지 않는59개다. 각 행의 `v1_lineage`는 원 행 위치·출처·본문 SHA·원 분할을 연결한다. `products.json`은 기존 세 제품 참조이며 새 설명서 수집이 아니다.

`snapshots/`는 작성자·사진·인구통계 없이 본문과 허용된 행 정보만 담은 공개 DOM 관찰 snapshot이다. 생략된457803의 원 본문·fragment SHA와 공개 생략본 SHA를 구분한다. 원60행의 전체 캡처와 연락처를 포함한 원 DOM은 비공개 작업 영역에만 보존했다. DOM capture를 다운로드한 서버 HTML SHA로 주장하지 않는다. 출처 URL·정렬·관찰시각·행 위치·snapshot 상대 경로는 각 행과 manifest에 있다.

`build_sidecar.py`는 고정 v1 세 JSON과 DOM 캡처·지문을 읽는 독립 연구용 빌더다. 최초 로컬 생성 뒤 독립 검수에서 생략할 업체명이 코드 literal에 남은 점을 발견해 표시된 업체 span을 읽는 일반 규칙으로 수정했다. 원 실행·finding은 비공개 기록에 보존했다. 최종 source commit `12d27f2c3d196536ea1bd15cfdda09ae44218abb`에서 고정 Docker의 network=none/auth=none/읽기 전용 입력으로 한 번 재검증했고, source3687파일·입력 변경0과 모델 호출0을 확인했다. 생성된11개 파일은 기존 생략 산출물과 byte동일이고 Excel도 그대로다. 제품 수집기·API·계약·웹·공개 CLI를 수정하지 않았다. v2 SQLite는 만들거나 Git에 추적하지 않았다.

Excel은 별도 사용자 outputs의 `LG_공개후기_최신순_낮은별점순_60행_R5V2.xlsx`다. 세 시트의 수식38개·총계60/59·원문60셀 일치·긴 본문62줄 재결합·날짜형·생략·정렬·필터를 확인하고 정상 크기 render를 읽었다. native Excel 앱을 열거나 모델 요약을 실행한 검증으로 바꾸지 않는다.
