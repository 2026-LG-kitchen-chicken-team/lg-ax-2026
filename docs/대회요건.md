## 주제 해석: 추가 자료를 반영한 기준

모집공고는 A를 새로운 키친 가전 기능·제품·서비스 콘셉트, B를 새로운 키친 경험·AI 기반 제품·서비스 설계로 소개한다. 추가 주제 자료는 이를 수행하는 **반복 실행 가능한 Agent** 개발로 구체화한다(S5 19~20쪽).

| 구분 | 수행할 역할 | 주요 과정 | 산출물 |
|---|---|---|---|
| Theme A | AI 상품기획 담당자 | 데이터 수집 → 트렌드·경쟁 분석 → 기회 발굴 → 인사이트 도출 | 근거를 갖춘 제품·서비스 콘셉트 |
| Theme B | UX/UI 시나리오 설계자 | 고객 상황 파악 → 시나리오 작성 → 서비스 흐름 구성 → 경험 검증 | UX 시나리오와 실행 결과 |

키친의 보관·준비·조리·세척 과정, 개인화, 가전 연결, 자원 절약 등의 문제를 다룰 수 있다. 구체적인 역할은 예시이므로 우리 Agent가 누구의 어떤 수고를 줄이는지 먼저 정한다(S5 28쪽). 후보를 소비자용 주방 앱으로만 좁히지 않는다.

## 포함 가능 과제의 해석(2026-09-27 보완)

공식 선택 단위는 Theme A/B다. 공고 표는 각 열의 항목을 ‘포함 가능 과제’로 표시하며 한 행만 택하거나 여섯 행 모두를 수행하라는 문구는 확인되지 않았다. 추가 자료 19~20쪽의 직무 흐름과 함께 보면 여러 항목을 자료·Skill·산출물로 연결할 수 있다고 해석한다. 이는 문서에 근거한 해석이며 운영기관의 별도 확인 답변은 아니다. 이전 12개 대표안은 탐색을 위한 구분이며 공식 12개 출품 부문을 뜻하지 않는다.

주제는 직접 사용자의 반복 업무와 결과물로 정하고 전체 주제·첫 구현·시연 사례를 분리한다. 항목을 많이 포함하는 것을 공식 가점으로 가정하지 않는다.

## 제출물

2. 제안서: **HWP 10쪽 이내**, 표·이미지 포함. 개요, 배경, 활용정보, 아이디어 설명·차별성, 추진방향, 기대효과의 6항목. 제출할 때 파란 안내 문구 삭제.
3. 개인정보 수집·초상권 사용 동의서: 구성원별 확인 및 서명.
4. 경진대회 참가 서약서: 구성원별 확인 및 서명.

접수 단계에서 완성된 Agent 제출이 필수라고 단정하지 않는다. S2는 1차 선발 후 실제 구현을 요구하므로 제안 단계부터 구현 가능한 범위로 설계한다.

## 평가와 제한

S5 30쪽은 문제의 명확성, 근거에서 얻은 인사이트, Agent의 계획·실행과 설명, 작동하는 구현물, 재사용성과 활용 가치를 평가 기준으로 제시한다. 당시 배점은 없었으나 **S6의 2차 기본 배점은 고객 문제 20·Agent 구조 20·실제 작동과 시연 10·핵심 기능 및 Skill 30·기대효과 및 확장 20점(합계 100점)**으로 확인했다. 토큰 사용량 절감은 가산점 대상이며 구체 점수·반영 방식은 추후 안내다. 단순 챗봇, 일회성 데모, 근거가 부족한 아이디어, 기술 나열에 대한 S5 감점 주의는 유지한다.

S5 31쪽의 발표 흐름은 문제 → 근거 → Agent → 작업 흐름 → 시연 → 인사이트 → 콘셉트 → 재사용이다.

S3는 동일 내용으로 다른 유사 대회에서 수상한 작품, 이미 상용화된 과제, 미비·허위 신청서를 제한한다. S4는 직접 창작·권리 준수와 표절·대리 작성·대리 발표 금지 등을 명시한다. S6는 바이브 코딩을 허용하되 미리 만든 결과 화면만 보여주거나 입력·판단·처리 없이 결과만 출력하는 방식은 인정하지 않는다. 실제 작동하지 않는 기능은 구현으로 평가하지 않는다. 별도 AI 이용 표기 의무는 S6에 명시되지 않았다.
