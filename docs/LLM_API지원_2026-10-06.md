- 마지막 메시지 원문: “LG전자 해커톤 대회 LLM API지원의 경우 비용이 아닌 팀별 API KEY를 발급해 예정 입니다.”
- 확인 가능한 내용: **LLM API 지원은 비용 지급 대신 팀별 API 키를 발급하는 방식으로 예정되어 있다.** 키가 이미 발급되었거나 사용 가능하다는 뜻으로 기록하지 않는다.
- 미확인: 공급사·API 주소·사용 가능한 모델·발급 시점·지원 한도·동시 호출/속도 제한·유효기간·제출 후 재실행 조건·지원 API 사용 의무·로컬/오픈소스 모델 병행 조건.

## 로컬·오픈소스 모델을 사용할 수 없는가?

**이번 문자는 지원 방식 안내이며, 로컬 LLM 금지나 제공 API 사용 의무를 명시하지 않는다.** 확인한 모집공고·주제 자료 요약·2차 제출 안내에도 지정 공급사/API 의무나 로컬·오픈소스 모델 금지 조항은 발견하지 못했다. 이는 확보한 자료의 확인 범위이며, 모든 후속 규칙에서 자유롭게 허용된다는 주최 측 확인을 대신하지 않는다. [대회 요건](대회요건.md)·[2차 안내](2차제출_평가안내_2026-10-03.md)를 함께 따른다.

따라서 기존 로컬 모델·검색·OCR 작업을 중단하거나 제공 API로 전면 교체하지 않는다. 제공 모델의 성능·한도·기간을 확인한 뒤 핵심 판단에 적합한지 비교한다. **제공 API와 로컬 모델을 병행할 수 있는지, 제공 API 사용 자체가 심사·지원의 조건인지**는 컨설팅에서 확인한다. 이 권고는 공급 API 채택이나 새 모델 비용 사용을 승인한 결정이 아니다.

## 우리 레포에서 활용할 위치

- 웹과 private MCP는 같은 상품기획 코어를 호출한다. 제공 API를 연결할 경우 서버의 `StructuredModelClient` 어댑터 경계에 추가하여 양쪽에서 같은 자료·검사·실행 이력을 사용한다.
- 현재 `packages/core/src/lgax_core/model_client.py`의 `from_env`는 `lab`/`ollama`만 허용한다. loopback 주소와 Ollama digest를 검사하며 공급사 API 인증·요청/응답 변환은 없다. **키만 설정하면 연결되는 상태는 아니다.** 새 공급사 연결과 모델 버전 확인·전체 호출/사용량·실패 기록이 필요하다.
- 제공 키는 참가작 서버의 추론 자격증명이다. 웹 작업실 로그인 토큰이나 ChatGPT·Claude 호스트 로그인, 팀원 Codex·Claude 개발 구독을 대체하는 것으로 해석하지 않는다.
- 로컬 공개 모델은 자료 검색·재정렬·OCR·로컬 비교/재실행 후보로 유지할 수 있다. 제공 API가 임베딩·OCR까지 지원한다고 가정하지 않는다. 로컬 경로 전환은 실행 기록에 명시하며 평가 중 조용히 다른 모델로 바꾸지 않는다.
- 기존 실측 6건과 후속 2건의 정상 기획 완료는 0건이다. 원문 인용·기능 지원과 잔여 불편의 구분·수정 피드백 보완은 계속 필요하다. 제공 API에서 같은 입력을 실행하기 전에는 품질 개선을 주장하지 않는다. [품질 근거](../evals/pm-intake/20261006/core-quality-review.md).
- Agent와 일반 LLM의 효과 비교는 같은 모델·입력·자료·출력/수정 예산으로 수행한다. 8B와 제공 모델의 비교는 별도 모델 비교 실험이며 Agent 자체의 효과를 입증하지 않는다. [평가 지침](pm/evaluation.md).

## 다음 확인과 담당

1. **정이량 PM·황대겸 팀장:** 컨설팅에서 공급사/API 규격·모델·발급일·팀 한도/속도·기간·종료 후 재현 조건과 제공 API 사용 의무/로컬 병행 여부를 확인하고 답변 출처·확인일을 기록한다. 아직 문의를 발송한 상태가 아니다.
2. **정이량 PM:** 규격과 사용 조건을 확인한 뒤 서버용 어댑터·키 보관·팀 공통 사용 한도·실패/토큰 기록의 작업 범위를 정한다. 지금은 구현/배정/실행하지 않았다.
3. **황대겸·신진하:** 기존 승인된 8B 품질 보완과 원문 독립 대조는 계속한다. 제공 모델 비교가 승인되면 같은 정상·조건 변경·근거 부족 사례를 사용하고 원 실패·수정/재시도 비용을 보존한다.
4. **최길웅:** 기존 웹 흐름과 자료 범위/원문 혼선 보완을 계속한다. 공급사 키를 클라이언트에 넣거나 별도 모델 호출 경로를 만들지 않는다.

**현재 상태:** 안내 기록·질문 준비 단계. API 키 발급/연결·모델 변경·지원 API 채택·새 비용 사용·품질 합격·전체 구현 완료가 아니다. 팀·개인 자동화 OFF와 기존 R2 배정/실행·비용 이력을 유지한다.
