# 하네스와 구현 검토 기록

## 최신 상태: 2026-09-27 후보 검증과 선정

사용자 위임에 따라 A4/B1/B5의 공개 자료와 최소 Skill을 비교하고 Theme A Kitchen Gap을 선정했다. `기획/주제검증_결과.md`와 `기획/최종주제_선정.md`가 현재 기준이다.

- `python scripts/topic_trial.py`: 정리된 입력을 사용하는 개발용 규칙 실험 **9/9** 통과.
- `python -m unittest discover -s tests -v`: 기존 23개 + 신규 9개, **32개** 회귀 검사 통과.
- `python scripts/topic_trial.py --check`: 저장된 출력과 현재 코드·입력의 재현 일치 검사. CI에 포함.
- 자료 해석·기능 태그·콘셉트 작성은 이 대화의 Codex가 수행. 원문 자동 추출·LLM API·실사용 수요·비용·지연을 검증한 것은 아니다.
- 주제 선정과 서류 접수는 별도 단계다. `gate topic`은 결정 기록과 검토 증빙을 검사하고, `gate submission`은 서류가 미완성이므로 계속 차단해야 한다.

## 검토 결론

- A/B 6개 후보와 B1 추천 후, 사용자의 추가 검토 요청에 따라 신규 5개를 조사했다. 현재 주제는 미정이다.
- PC·웹에서 장치 기능 목록과 시나리오 JSON을 검사하는 코드는 실행 가능하다.
- 이 결과는 **제약 검사부의 소규모 실현성 확인**이다. LLM 연결, 생성·수정 루프, 웹 UI, 제품 명세 수집, 실제 UX 효과가 구현·검증된 상태는 아니다.
- 핵심 미확인: 모델/API 가용성·비용, 모델별 기능 목록, 현업 사용자 수요. 대책은 `기획/추천안_구현검토.md`에 기록했다.

## 검증 범위

로컬 검증 결과: 기록 검사와 Python 회귀 테스트 수행. 미확정 주제와 미완성 접수 점검은 gate에서 예상대로 차단되어야 한다. 최종 테스트 개수와 GitHub Actions 결과는 실행 로그와 PR에서 확인한다.

`python scripts/harness.py validate`: 출처 참조, 상태 구조, 완료 증빙 파일·해시 검사.

`python -m unittest discover -s tests -v`: 출처 누락, 위조된 완료 상태, 변경된 증빙, 경로 이탈, 주제 미확정, 삭제된 점검 항목 등 차단. 시나리오 정상/충돌/순환/미지원/잘못된 입력 검사.

`python scripts/scenario_spike.py`: 합성 시나리오 3개. 정상 입력은 위반 없음, 충돌 입력은 자원 중복과 선행 미완료를 검출, 미지원 입력은 지원하지 않는 기능을 검출. 실제 가전/API 호출 없음.

`gate topic`과 `gate submission`: 미확정/미작성 항목을 통과시키지 않는지 별도 확인. 문서가 있다는 이유만으로 접수 완료가 되지 않는다.

## 판단의 한계

소규모 규칙 테스트는 전체 참가작의 성능 지표가 아니다. 사용자 편의성·고객 수요·LLM 품질·실기기 동작을 입증하지 않는다. CI도 주제의 우수성·서명의 진위·HWP 실제 페이지 수·신청 성공 여부를 판단하지 않는다.
