# 오늘 접수 완료 계획

기준: 2026-09-27 KST. 공식 마감은 **9/28 18:00**이지만, 사용자는 **9/27 오늘 접수 완료**를 목표로 정했다. 이전 내부 목표인 9/28 15시는 폐기한다.

## 현재 완료 범위

- 공고·자료 확보, 저장소와 관리 하네스 준비.
- 3개 후보의 자료 접근·중복·최소 Skill 실행 검토.
- 사용자 위임에 따른 **Theme B Kitchen Recovery 재선정·초기 설계**, [범위 결정서](../기획/AtoZ_재선정과_Agent설계.md) 작성.
- 모델 API·원문 추출·생성 성능과 사용자의 실제 효용은 미검증. 이번 규칙 실험을 완성 Agent로 표현하지 않는다.

## 오늘 남은 순서

1. 선정안으로 공식 6항목 원고 작성. 기존 B1 초안을 그대로 쓰지 않는다.
2. 팀명·팀장·참가자격·누락 인적 사항·전원 서명을 문서 작성과 병행 취합.
3. 공식 HWP 신청서·10쪽 이내 제안서·동의·서약 양식 반영.
4. 파일 열림·분량·서명·내용 일치와 실제 업로드 조건 확인.
5. 온라인 신청 후 완료 화면·제출본·시각을 `private/`에 보관.

최신 목표에 따라 AtoZ 하네스와 탐색~선정·Agent 초기 설계를 완료했다. HWP와 온라인 접수는 아직 진행하지 않았다. 개인 정보·서명·로그인처럼 팀이 제공해야 하는 부분은 별도 필요하다.

오늘 접수 준비와 무관한 인프라 확대, 다중 Agent 실행기, 실기기 제어, 대규모 크롤링, 완성 UI 구현은 후순위다. PC에서 핵심 Agent를 개발·시연하되 미래 가전·서비스 콘셉트를 웹으로 제한하지 않는다.
