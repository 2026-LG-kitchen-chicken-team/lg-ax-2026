사용자 지시 원문: PR187의 sku-application.json에서 미확인 SKU-F03·F04·M01·M02만 추가 조사해줘. 정확한 모델명이 연결된 LG 공식 구성품·부품도·사용 안내에서 근거를 찾고, 확인/상충/미확인을 구분해 새 근거표를 작성해. 기존 PR187 파일·자료팩·코드는 수정하지 말고 별도 작업 공간과 고유 폴더를 사용해. 모델 호출·실기기 조작 없이 조사 결과를 보고해. 이것도 하고 pr올려.

수행: 정확 모델 제품 페이지·공식 교체 부품/호환표·공용 설명서를 읽고 원본 hash를 연결했다. 별도 worktree/고유폴더를 사용했다. M01 문서상 적용은 새로 확인; F03/F04는 장착/호환 근거를 추가했지만 기본 출고 포함은 미확인; M02 직접 저장/재호출 근거는 미확인. 현재 MJS 트레이 후보 검색0건, AEQ 손잡이형 부품 정확 서비스 모델1건을 확인했다. 모든 원문/판정/질문은 새 표에 있고 원 PR187 파일9개는 byte 유지했다.

실패/한계: 웹 도구가 일부 URL의 직접 열기/find에서 오류를 반환했다. 같은 공식 URL을 현재HTTP로 읽고 원본hash를 남겼으며 렌더링 브라우저에서 적용 모델/구성 안내를 확인했다. 설명서 표지 문자층의 깨짐은 원본 페이지 렌더로 확인했다. HTML에 기존PDF fileId가 직접 보이지 않아 현재PDP 동적 다운로드와 동일파일의 직접 연결은 미확인으로 명시했다. 출고 BOM을 확보한 것으로 과장하지 않았다.
