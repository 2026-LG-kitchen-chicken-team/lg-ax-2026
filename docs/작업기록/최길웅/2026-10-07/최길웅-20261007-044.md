## 2. 해석(AI 해석)
- #188이 미병합이라 그 head의 서버 코드를 그대로 쓴다. 자료는 #188의 서버 옵션(`--dataset`, `--trend-metadata`, `--trend-metadata-sha256`, `--allow-candidate-trend-metadata`)으로 연결한다. 기록 040처럼 저장소를 바꿔 끼우지 않는다. 시험 DB는 따로 쓴다(`private/workspace-r4-pmdated`, git 제외).
- 서버가 맞는지는 서버 코드를 믿지 않고, 날짜팩 원 파일에서 독립 규칙으로 다시 계산해 대조한다. 규칙은 다음과 같다.
  - day는 그 날짜, instant는 KST로 변환한다.
  - dedup_key가 같으면 중복으로 본다.
  - 계절은 3·6·9·12월에 시작하며, 1·2월은 전년 겨울이다.
  - 분모가 0이면 비율은 null이다.
- 웹은 같은 프로젝트·같은 필터에서 같은 집계 ID가 나와야 한다. 모든 주제의 모든 막대가 API 숫자와 같아야 하고, 빈 구간은 '자료 없음'(0%가 아님)이어야 한다.
- #201 미병합 상태에서도 결과가 같도록, 시험은 사용자가 하듯 제품군 카드와 검토 모델을 직접 고른다.
