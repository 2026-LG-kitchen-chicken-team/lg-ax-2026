## 2. 해석(AI 해석)
- 원문의 `locator`는 형식이 정해지지 않은 객체다. 실제 R8 묶음에는 10가지 형태가 있다(근거 058).
  - 리뷰 번호+페이지 선택자, 설명서 쪽+항목, FAQ 문단/문단 범위/단계/적용 모델, 설치표 표·단위, 사양 제목 앞, Q&A 질문 번호·페이지 모델 ID·날짜 항목·문단 주제
- 사람이 읽을 수 있는 위치 문구로 바꿔 원문 행·원문 상세·사실(facts) 목록·두 Markdown 내보내기(기획안, 선택 자료)에 보여 준다.
- 페이지 선택자(CSS selector)는 기술 정보라서 상세의 접힌 영역에만 둔다.
- 모르는 키도 버리지 않고 `키: 값`으로 보여 준다. JSON 내보내기는 원문을 그대로 복사하는 규칙이 있으므로 바꾸지 않는다.
