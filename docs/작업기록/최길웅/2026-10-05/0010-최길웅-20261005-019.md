#### 해석과 범위
- 목표: 최길웅 PC에서 `engine=claude` Worker가 동작할 준비를 갖추고, 점검(`--preflight`)까지만 실행한다. 팀·개인 모드는 OFF를 유지하고 모델 실행·코드 게시를 하지 않는다.
- 가정: Codex 대신 Claude Code 실행기를 선택했다(지침상 Claude 사용자는 Codex 인증 불필요). 실행 계정 분리는 아직 하지 않았으므로 `isolation_acknowledged=false`로 둔다.
