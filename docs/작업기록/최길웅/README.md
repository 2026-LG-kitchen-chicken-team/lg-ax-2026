### 작업 안전 규칙 (모든 최길웅 AI 세션이 작업 전 먼저 지킨다, 기록 015)
- **쓰기 세션은 하나만:** 이 기록·근거 문서와 같은 브랜치를 고치는 세션은 한 번에 하나다. 새 세션을 열기 전에 이전 세션의 commit·push를 끝내고 이전 세션을 닫거나 읽기 전용으로만 쓴다(PC·클라우드·모바일 포함).
- **시작 시 확인:** `git fetch origin` 후 (1) 내 브랜치 원격 head가 로컬과 같은지(다른 세션이 push했는지), (2) main이 이 기록 파일을 바꿨는지(`git log <내 브랜치>..origin/main -- docs/작업기록/최길웅.md docs/작업근거/최길웅.md`, PM 인수 포함)를 본다. 다르면 먼저 합치고 시작한다. 덮어쓰지 않는다.
- **PM 인수 뒤에는 main 기준으로:** PM이 내 PR을 선택 인수했으면 기존 브랜치에 계속 쌓지 말고 최신 main에서 이어간다(PR #61·#64 충돌 참고).
- **설치·서버 분리:** `npm ci` 대신 `npm run ci:safe --prefix apps/web`(5173 사용 중이면 거부). 사용자 개발 서버가 도는 폴더에서 설치·E2E를 돌리지 않고 별도 worktree를 쓴다. 시험용으로 띄운 서버·포트 점유 프로세스는 끝나면 PID로 직접 종료하고, 남은 프로세스가 없는지 확인한다(`pkill -f`는 자기 셸까지 끌 수 있어 쓰지 않는다).
- **git 동시 실행 금지:** 같은 clone에서 두 세션이 동시에 fetch/commit하지 않는다(`incorrect old value provided` 원인).
