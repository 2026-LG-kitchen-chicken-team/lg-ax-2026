## 실제 구현 의도

기존 화면은 설정→이력→긴 기획 결과→원문 순서로 쌓이고 본문·인용 조작이 작아 첫 방문과 모바일에서 결과를 찾기 어려웠다. 원문은 실행 이력과 결과 앞으로 옮기고 고정 바로가기로 설정·원문·리뷰 분석·개선 장면·관계·이력으로 이동한다. 이동은 제목 포커스를 전달하며 API·모델 요청을 발생시키지 않는다. 저장 결과 불러오기와 실행 결과 선택은 결과 제목으로 포커스를 옮긴다.

첫 화면에는 현재 선택한 자료의 실제 원문 수·현재 선택 수·열린 기획 초안 수를 표시한다. 자료 연결 전 숫자는 미확인 표시이며 저장 기획의 입력 범위와 현재 선택이 다를 수 있음을 표시한다. 결과 첫 카드에는 첫 문제와 problem_id/problem_ids로 명시적으로 연결된 기존 대응·개선안만 넣는다. 연결이 없으면 자료 없음으로 표시하며 연결·문장·새 근거를 생성하지 않는다.
