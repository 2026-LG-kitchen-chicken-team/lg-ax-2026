# 4인 팀 변경 반영 및 서류 검수

2026-09-27 사용자의 긴급 지시로 황대겸을 LG AX 해커톤 팀에 추가했다. 기존 3인 최종점검 기록 이후의 변경이며 현재 제출본은 아래 파일을 따른다.

## 사용자 확인과 반영

- 팀명 키친에서치킨먹기, 정이량(팀장)·신진하·최길웅·황대겸 4명이다.
- 황대겸은 컴퓨터공학과 3학년이다. 학번과 연락처를 사용자가 직접 제공했으며 값은 `private/team.json`에만 저장했다.
- 사용자에게 황대겸의 창원캠퍼스 재학, 개인정보·초상권 두 항목 동의, 이름의 필기체 이미지 작성·삽입 승인을 추가 확인했다. 기존 세 명의 동의를 자동 확장하지 않았다.
- 신청서의 네 번째 행과 서명, 동의서·서약서의 네 번째 이름과 서명을 반영했다. 원본의 다섯 번째 행은 비워둔 예비 칸이다.
- 제안서의 ‘3인 협업’을 ‘4인 협업’으로 바꾸고 Agent·도구 / 데이터 / UI / 평가·문서를 분담하는 계획으로 맞췄다. 개인별 역할을 이미 확정했다고 쓰지 않았다.

## 최종 파일과 검수

- 최신 HWP: `private/제출준비/LG_AX_키친에서치킨먹기_4인최종본_v2.hwp`
- 검토용 PDF: 같은 이름의 `.pdf`. 이전 3인·4인 배치 검토본은 보존했다.
- 전체 11쪽, 제안서 8쪽, 그림 5장·사용 예시 3종으로 분량과 주제를 유지했다.
- 필기체 이미지 4개와 서명 배치 12곳을 확인했다. 기존 세 명의 이미지 원본은 유지했다. 황대겸은 내장 imagegen으로 새 필기체를 만들었으며 실제 필적을 복제한 것이 아니다.
- 생성 지시 요약: ‘황대겸 한 번만, 빠르고 느슨한 검정 볼펜 손글씨, 낮고 넓은 비율·약한 왼쪽 기울기·불규칙 간격, 투명 배경, 인쇄체·장식·밑줄 없음’. 이미지와 상세 생성 기록은 `private/서명/황대겸.png`, `private/서명/manifest.json`에 있다.
- 동의서에서는 필체의 비율을 유지해 각 행 안에 들어가도록 표시 크기를 조정하고 하단 여백과 이름/서명 정렬을 확인했다. 원본 `(서명/인)` 문구 위 배치는 사용자 요청대로 유지했다.
- 최종 HWP를 한글에서 다시 열어 11쪽과 전체 텍스트 일치를 확인했다. PDF 11쪽을 렌더링하고 수정된 1·8·10·11쪽을 시각 검수했다. 나머지 7쪽은 이전에 검수한 렌더와 파일 해시가 동일하다.
- 네 명의 이름·학과·학년·학번·연락처, 팀장 이메일, 두 동의 원, 4인 협업 문구를 HWP/PDF에서 대조했다. 공식 6항목과 행정 본문 16개 주요 구절, 공식 원본 파일을 보존했다.

## 남은 항목

최신 4인 제안서·참가서약의 팀 최종 검토, 로그인 후 업로드 조건 확인, 실제 온라인 접수와 증빙 보관은 별도다. 팀원 추가 동의 확인을 최신 제안서 전체 검토 완료로 기록하지 않는다. 참가작 Agent 구현·효과 측정은 이번 문서 수정에 포함되지 않는다.

개인정보와 완성 서류·검수 이미지·해시는 Git 제외 `private/`에 있다. AtoZ의 산출 계약 검증과 실제 접수 완료를 구분한다.
