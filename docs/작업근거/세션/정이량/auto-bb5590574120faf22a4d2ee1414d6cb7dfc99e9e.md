승인 패킷의 아래 두 명령은 이 프로세스에서 실행하지 않았다. 별도 인증 없는 validator에서 실제 실행·exit·stdout/stderr·고정 파일 해시를 보존해야 한다.

```sh

uv run --offline --no-sync python -m unittest tests.test_skill_runner -v
```

후속 순서: 파일 bytes/승인 경로 대조 → 위 두 검사 → 결과 보존 → 허용된 publisher PR/CI → PM의 독립 인수/실제 병합/통합. 실패 시 원 job/실행 결과를 보존하며 이 기록의 정적 검토를 trusted 통과로 승격하지 않는다.
