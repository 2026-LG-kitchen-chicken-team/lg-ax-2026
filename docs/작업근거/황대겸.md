# 황대겸 — 작업근거

작업 의도·진행: [황대겸 기록](../작업기록/황대겸.md). 형식: [공통 규칙](../작업기록/README.md#근거-문서-형식).

## 현재 상태

황대겸 담당 AI의 실제 작업근거는 아직 없다. 구현/검사 후 고유 근거 ID·관련 기록·입력·모델/설정·원본/출력 위치·실행 결과·결론·한계를 남긴다. 다른 팀원이나 현재 Codex가 문서 틀을 만든 것을 본인의 Agent 실행 증거로 사용하지 않는다.

## 근거 기록

실제 자료조회·의미 판단·인용/중복 검사·수정/보류·변경 재검토가 실행되면 [공통 근거 형식](../작업기록/README.md#근거-문서-형식)으로 추가한다. 실제/모의 모델, 자료의 합성 여부, 독립 평가와 개발 예시를 구분한다.
