# 수동 공유 프로토타입 — 2026-10-08

사용자 지시: 링크를 가진 팀원이 사용할 수 있게 웹/API·LLM을 열고, 사용자의 종료 지시 전 시간 경과를 이유로 자동 종료하지 않는다. 범위는 프로토타입 제공이며 자동 Worker·예약 배정은 OFF를 유지한다.

배포 대상은 main eab85d4에 기반한 디자인 PR #275와 이번 공유 서버 후보다. 배포를 main 병합·판단 의미 품질 승인·부모 작업 Done으로 표시하지 않는다. 실제 공개 자료 10묶음을 사용하며 새 합성 리뷰는 만들지 않는다.

`scripts/serve_shared_research_prototype.py`는 별도 HTTPS 게이트웨이·브라우저별 서명된 editor 세션·독립 SQLite를 제공한다. 외부에는 정적 웹과 실제 자료 `/api/research/`만 노출한다. 기존 작업실·공개 MCP·PM/하네스 제어는 열지 않는다. 요청 출처/Host를 정확히 확인한 뒤 내부 기존 allowlist에 맞춰 전달하며 생성/수리는 하나씩 실행한다. 다른 실행이 처리 중이면 명시적으로 재시도 안내하고 자동 재전송하지 않는다.

`scripts/start_shared_prototype_model.py`는 기존 고정 Qwen 27B 캐시·binary/digest를 확인하고 여유 있는 GPU3 전용 포트18875만 사용한다. 기존 Naru/GPU1·다른 팀원의 프로세스/자료는 변경하지 않는다. 모델 서버와 요청 양쪽 keep_alive=-1이며 1700/1800초 테스트 세션 종료 코드를 사용하지 않는다. 단일 요청의 기존4콜·출력4096·문맥16384·응답180초 제한은 서버 수명과 별개로 유지한다.

서버·터널은 연구실의 사용자 서비스로 실행한다. RuntimeMaxSec=infinity, Restart=always이고 SSH/현재 AI 턴의 종료와 분리한다. 자동화 OFF는 개발/배정 Worker에 적용하며, 사용자가 직접 요청한 서빙 서비스의 생존/장애 재시작과 구분한다.

공유 연결은 사용자가 명시적으로 종료할 때 해당 전용 서비스 세 개만 정지한다. 하드웨어/네트워크 장애에는 중단될 수 있으며 현재 모델 캐시는 tmpfs라 연구실 재부팅 후 재확보가 필요하다. Cloudflare Quick Tunnel 주소는 프로세스가 새로 만들어지면 바뀔 수 있다. 기존 Tailscale 경로는 보존하며 새 포트 추가는 실제 권한 부족으로 적용하지 않았다.

완료 증거는 정이량의 날짜별 공유 서빙 작업/근거와 배포 receipt에 기록한다. 실제 모델과 독립 의미 검수는 구분하며 AI 초안은 원문 확인이 필요하다.
