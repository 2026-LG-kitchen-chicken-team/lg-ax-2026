## 고정 실행 환경과 첫 품질 확인

- 연구실 LG Ollama0.34.0: loopback18864, private model API18865. 기존 중앙 모델 proxy는 PM PC localhost18871→연구실18871 중계와 외부 LG 경로를 사용한다. 팀원은 기존 본인 인증·수동 예약·격리 실행을 재사용하고 인증정보를 다른 사람에게 공유하지 않는다.
- 모델은 **qwen3:8b**, digest `500a1f067a9f782620b40bee6f7b0c89e17ae61f686b92c24933e4ca4b2b8b41`. 기존 고정 샘플링·context/output 조건과 실제 입력/응답 전문·재시도 비용을 보존한다. 원본 고정 자료와 별도 수정 입력의 SHA를 분리한다.
- 첫 배치는 냉장고 정상1·같은 목표 조건변경1·정당한 근거부족 보류1로 제한한다. 최대3입력·실제 모델 호출24회 이내이며 중앙 남은 허용 한도/토큰 제한이 더 낮으면 그 제한을 따른다. 내부 Agent 수정은 전체 공유2회, 사용자 조건변경 회차와 분리한다. STOP·예산·연결 실패시 자동 재전송하지 않고 원 요청·비용·이유를 인계한다.
- 정상 입력은 개발 샘플이고 독립 평가 답안을 넣지 않는다. 실제 accept는 기존 기능의 존재와 잔여 불편을 분리하고, 후보→Gap→Need→리뷰/설명서·차별점·요구사항의 원문 연결과 제외 조건 준수까지 독립 대조한다. accept 수를 올리기 위해 보류·검사 조건을 낮추지 않는다.
- LG27B 캐시는 직접 조회에서 없고 영구 저장 공간은 여유15GB였다. 임시 공간은 재부팅으로 사라질 수 있다. **27B 재설치/비교를 첫8B gate의 선행 조건으로 두지 않는다.** 기존27B 실패/평가를 보존하며 같은27B1건은 LG전용 모델·공간·고정 버전 확보 뒤 별도 유한 실행으로 이어간다. 다른 프로젝트 GPU/모델/경로는 변경하지 않는다.
