## 실제 반영 범위

PR163의 원 실패와 실행 자료, PR158/164의 웹·내보내기를 고정 head로 선택 인수했다. 원 누적 기록을 새 호환 목차 위에 덮어쓰지 않고 원bytes snapshot4개·추가 구간 diff2개·기존 세션6개·source manifest로 보존했다. [원PR/파일 대응](../../evals/pm-prototype/20261006/pr-intake/source-manifest.json)을 따른다.

냉장고 concept_draft와 전자레인지 semantic_review에서 전체 스키마를 텍스트에 중복 붙이던 입력을 보완했다. native 스키마를 실제 강제하는 backend만 본문 중복을 생략하고 `format`/local validation/원 SHA/전후 digest 검사는 유지한다. 파생 근거 그래프의 중복 설명만 ID·검증 annotation으로 전달하며 canonical 원문·기능·입력·모든 lineage links/수치/위반과 전체 quality trace는 보존한다. 기록 입력 재구성의 최종 길이는14,997/13,254자로16,000자 guard 안이다. Lab/미확인 backend는 전체 텍스트 스키마를 유지한다.

웹 동향은 월별/계절별 그래프·분모/표본·원문 조회·기획 연결·JSON/Markdown 내보내기를 인수했다. 제품/모델/자료/출처/기간/로그인/프로젝트가 바뀌면 이전 결과를 무효화하고 늦은 응답을 거부한다. 범위 밖 모델을 몰래 첫 모델로 대체하지 않는다. 응답 필터·자료 hash·원문 문서 개정도 대조한다. 서버 collector 미연결/501은 정상 숫자로 대체하지 않는다.
