# 공식 발췌 안내와 가상 제품 기획 설명서 X1

현재 채팅의 수동 지원 구현입니다. 모델을 부르지 않고 이미 보존한 자료와 기획 필드를 조립합니다. AI가 실제 새 제품의 설명서를 완성했거나 기획 품질 검사를 통과한 것으로 표현하지 않습니다.

## 두 종류의 문서

- `build_official_guide(bundle, page_model)`은 해당 페이지 모델이 명시된 공개 공식 manual만 선택합니다. 현재 확인한 LG·Samsung 공식 도메인에서 가져온 자료를 사용하며, 다른 모델이나 고객 리뷰로 빈 설명서를 대신하지 않습니다. 원문·facts·URL·locator·문서판·coverage를 그대로 복사합니다. 출력은 항상 **공식 설명서 발췌 안내**이며 전체 정식 설명서를 대체하지 않습니다. 새 기기 설정·사용 수치를 만들지 않습니다.
- `build_concept_guide(bundle, brief, concept_id)`은 같은 bundle/scope/원문 facts에 연결된 기존 콘셉트만 받습니다. after_steps·visual_scenes·assumptions·확인 질문은 **가상 제품 기획 설명서 초안**의 제안 영역에 표시합니다. 관련 문제의 원문과 반대 자료도 실제 근거 영역에 별도로 보존합니다. 실제 구현이나 독립 품질 승인으로 승격하지 않으며, private runtime 기록은 내보내지 않습니다.

HTML은 외부 글자를 이스케이프하고 외부 스크립트·폰트·이미지 없이 구성합니다. 제안의 전후 과정·장면은 카드로 보여 주며, 원문·발췌·문서판·출처를 표시합니다. 인쇄 CSS와 A4 여백을 포함합니다. Markdown도 외부 HTML과 마크업을 이스케이프합니다. JSON에는 원자료와 제안이 분리된 구조가 그대로 보존됩니다.

## 내보내기

```powershell
$env:PYTHONPATH='packages/core/src;packages/contracts/src'
python scripts/export_research_guide.py --bundle <실제-bundle.json> --page-model MW23FDI --output-prefix <출력폴더>/MW23FDI-guide
python scripts/export_research_guide.py --bundle <실제-bundle.json> --brief <저장된-brief.json> --concept-id <기존-concept-id> --output-prefix <출력폴더>/concept-guide
```

각 실행은 같은 prefix의 `.html`, `.md`, `.json`을 만듭니다. 모델 호출은 0회입니다. 입력 파일을 출력으로 덮을 수 없으며, 이미 존재하는 출력은 새 prefix 또는 명시적인 `--overwrite`가 필요합니다. 기획 결과가 없으면 가짜 콘셉트를 만들지 않고 해당 export를 거절합니다.

## 검사 범위

기존 실제 공개 후기 837305와 공식 MW23FDI M11 자료를 재사용합니다. 원문·facts·수치 보존, 해당 모델 공식 manual 한정, 자료 없는 모델 거절, 두 문서 종류와 실제 근거/제안 영역의 구분, HTML·Markdown 이스케이프만 검사합니다. 콘셉트 표시 검사는 명시적인 test-only `needs_sources` 계약 입력으로 수행하며 실제 모델 답변이나 승인 기획의 fixture가 아닙니다. 고객 리뷰를 합성하지 않습니다. 모델 품질·API/UI 연동·실제품 사용 안전성은 이번 산출물 검사로 입증하지 않습니다.

신규 검사 4개와 수정 파일 Ruff, CLI 도움말이 통과했습니다. DATA의 실제 3묶음에서 MW23FDI 3발췌·DUE6BGL2E 6발췌·T876MEE1H1 6발췌를 HTML/MD/JSON으로 내보냈습니다. 정적 HTML의 실제 브라우저 화면·인쇄 결과 판독은 이 단계에서 확인하지 못했습니다.
