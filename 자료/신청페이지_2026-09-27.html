[LG전자와 함께하는 국립창원대학교 AX해커톤 대회]


AI로 상상하고 현실로 만들어 보는 세상

LG전자와 함께하는 국립창원대학교 AX 해커톤 대회

- 대회주제 : Theme A/B 중 선택(붙임2,LG키친솔루션_해커톤주제 참고)


 

  * 아이디어만 제출하는것이 아니라 1차 선발 후  작동하는 Agent ·skil l구현이 가능해야함 

 

- 참가대상 : (1) 국립창원대학교 재학생(대학원생 포함)

              (2) 5인 이내로 구성된 팀 단위 참가(대학원생 최대 2명 포함가능)

 

- 대회일정

 

* 서류접수 : 26. 9. 28.(월) 18:00까지

 

* 1차심사 : 26. 10. 2.(금) / 팀별 결과 공지(최대 12팀)

* 2차심사 : 26. 10. 21(수)/ 팀별 결과 공지(6팀)

   

* 발표심사 : 26.10.28(수)/ (시연 및 발표10분+ 질의응답 5분)

 

- 제출내용

 

1) 서류평가 : 10페이지 이내의 아이디어 제안서 제출(붙임파일)

  - 참가신청서로만 평가

2) 발표심사 : 20페이지 이내의 발표자료 제출(양식없음)_Agent 구현 필요

   

- 시상내역

 

* 대상 : 1팀 / 국립창원대학교총장상

* 최우수상 : 1팀 / LG전자상

* 우수상 : 1팀 /  LG전자상

* 장려상 : 3팀 / 국립창원대 산학부총장상, 인공지능원장상, 앵커사업단장상 

- 참가특전 : 앵커마일리지 부여 등

 

(* 세부 내용은 사업운영 현황에 따라 변경될 수 있음)
