# 자료 목록과 출처

## 이관 원본

`공모전 계획/공모전 자료/LG`의 아래 5개를 2026-09-27에 복사했다. 원본과 복사본의 SHA256이 모두 일치한다. 상세는 `이관목록.json`, 원 다운로드 URL은 `원본출처.json`에 있다.

| 파일 | 용도 |
|---|---|
| 공식/01_모집공고.hwp | 일정·참가·시상·제한사항 원본 |
| 공식/01_모집공고.txt | 기존 확인용 추출본, 일부 제어문자·표 순서 손상 가능 |
| 공식/02_참가신청서.hwp | 신청서·제안서·동의서·서약서가 포함된 원본 |
| 공식/02_참가신청서.txt | 기존 확인용 추출본, 제출 양식 아님 |
| 공식/03_포스터.pdf | 기존 포스터 원본 |

## 이번에 추가한 자료

- `공식/04_LG키친솔루션_해커톤주제.pdf`: 공식 신청 페이지에 첨부된 32쪽 이미지 기반 PDF. [원문](https://anchor.changwon.ac.kr/r/VW0Hl5Z2CnQp). 표지 제목은 '미래 키친을 만드는 사람들'. 페이지에 'LG Internal Use Only' 표기가 있다. 원본은 로컬 참고자료로 보관했다.
- `신청페이지_2026-09-27.html`: 앵커사업단 신청 상세 공개 페이지를 저장한 당시 스냅샷. 접수 결과가 아니다.
- `이전_LG_노션초안.md`: 이전 프로젝트의 `notion_children_draft.json`에서 LG 항목만 추출한 참고본. 팀 미확인·마감 시각 미확인 등 오래된 내용이 남아 있으므로 현재 상태는 README와 docs를 따른다.

PDF 텍스트 추출을 시도했으나 본문이 추출되지 않아 생성된 TXT는 유효한 본문 자료로 사용하지 않는다. 페이지 렌더링을 통해 핵심 내용을 확인했으며 `docs/대회요건.md`에 페이지별 근거를 기록했다.
