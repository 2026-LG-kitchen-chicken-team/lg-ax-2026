# OCR 검수 PR 인계

현재 폴더는 기존 14영역 OCR과 원본 PDF의 수동 검수 결과 사본입니다. 새 모델/OCR 호출은 0회입니다.

- 검수표.md는 GitHub에서도 근거 파일을 열 수 있도록 상대 경로를 사용합니다.
- JSON/CSV의 원 PC 절대 경로는 원 실행의 provenance입니다. 열람용 PDF/이미지는 inputs와 renders에 함께 보존했습니다.
- 원문 기준 확인과 자동 표 추출 미확인을 구분했습니다. 표 모델 연결 정확도·오류율은 null입니다.
- 각주 번호의 숫자 필드 혼입은 기존 평가 처리 문제로 분리했으며 코드·원 OCR·gold·성적을 수정하지 않았습니다.
- 표지 문자층 추출 깨짐, 도구/집계 준비 중 실패와 복구는 검수표의 실행 기록에 있습니다.
- 원문 14영역과 과거 70회, 문맥 19항목을 대조했고 원 입력 13개를 보존했습니다.
- 재분석 helper는 원 PC 경로와 기존 입력을 전제로 합니다. 다른 PC에서 그대로 실행할 수 있다고 주장하지 않습니다.
- #14 전체 검색 모델 비교·PM 인수·부모 Done은 별도입니다.
