## 실제 계약에 따른 주의

- Review/Evidence 본문에는 `dataset_version`/SHA를 추가할 수 없다(`additionalProperties:false`). 버전은 record.dataset, 원파일 SHA는 record.sha256, 원문 SHA는 origins.text_sha256에서 대조한다.
- CSV 개별 evidence는 보존 CSV를 다시 import하는 store 경로를 통해 나간다. **API evidence가 맞아도 DB의 저장 record가 같다고 결론 내릴 수 없어** DB export를 별도로 받는다.
- 정상 응답은 `{ok:true,data:...}`이고 GET search의 `items`는 현재 계약의 검색 항목을 따른다. `search_method=literal_token_count`는 공개 API 방법명이며 BGE/BM25 실측이 아니다.
- 로컬 documents 서버의 틀린 version 상태는400, public API는404다. 오류 code를 함께 대조하고 서버 profile을 고정한다. 미등록 모델은 `INVALID_MODEL_ID`, 틀린 version은 `INVALID_DOCUMENT_VERSION`이다.
- 아래 `handoff-template.json`은 **이 검수기의 입력 양식**이다. 공통 API/Schema 채택·실제 응답·승인된 새 팩을 뜻하지 않는다.
