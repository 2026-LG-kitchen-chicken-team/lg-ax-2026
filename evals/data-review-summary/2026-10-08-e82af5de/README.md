# 자료 조사와 냉장고 AI 답변 검수 결과

신진하(DATA)가 2026년 10월 8일까지 확인한 내용을 모았다. 역할은 제품 설명서·후기·설치 자료의 출처를 정리하고, AI가 그 원문과 조건을 정확하게 사용했는지 대조하는 일이다. 각 항목은 해당 근거의 확인 시점을 기준으로 한다.

| 조사·검수한 것 | 확인한 결과 | 아직 확정하지 못한 부분 |
|---|---|---|
| 냉장고·식기세척기·전자레인지 설명서 | 초기 공식 PDF 3개와 기존 근거 21개를 재사용했다. 확장한 15모델 설명서 후보의 모델·판본·조건 연결을 확인했다. 정확 모델 명시 5개와 공용·패턴 조건부 10개를 구분했다. | 공용 설명서에 있다는 이유만으로 모든 모델에 같은 기능이 있다고 확정할 수 없다. 실제 구매 모델·옵션과 구매 당시 설명서 판본이 일부 미확인이다. |
| 실제 후기 자료 | 중복을 정리한 기존 238건과 개발 입력 141행의 원문 ID·중복·제외 대상을 유지했다. 추가 후기 후보는 별도로 보관했다. | 개발 141행의 게시일 근거가 부족하다. 구매일은 게시일로 세지 않았고, 월·계절 집계 분모는 0, 비율은 null(계산하지 않음)을 유지했다. 주제 분류는 승인 대기다. |
| 설명서 표와 설치 Q&A | 기존 수동 검수의 모델별 숫자·단위·각주를 연결했다. 식기세척기의 안쪽 600mm·문 앞 590mm·조건부 567~600mm와 배관·기사 확인 조건을 대조했다. | 실제 자동 추출 표와 승인된 추출 설정을 받지 못해 자동 표 정확도는 검증 불가다. 특정 주방의 설치 가능 여부도 이 자료만으로 확정하지 않았다. |
| 경쟁제품·김치냉장고·광파오븐 | 기존 공식 경쟁자료 12건과 추가 가전 자료를 재사용했다. 김치냉장고·광파오븐 설명서 후보 2개의 모델·판본·페이지·설치 조건과 후기 후보 6건의 구매일 표시를 확인했다. | 용량·설치 형태·비교 시점·시험 조건의 차이를 구분했다. 공용 설명서의 기본 구성품과 정확 구매 모델의 기능, 모든 자료의 실제 기획 사용 여부는 미확인이다. |
| 냉장고 AI 답변 | 정상 답변 17항목과 조건 변경 자료 8항목을 원문과 대조했다. 이후 조건 변경 전체 응답의 54개 출력 위치를 추가로 연결했다. 의향과 경험, 사용기간, 소음 표현, 기능 조건·인용 누락을 구분했다. | 시스템 보완 전 응답이다. 최신 수정 효과나 최종 정확도 점수는 확인하지 않았다. 기존 두 실행 원본·동일 7입력의 비교 출력·정답 없는 4문항의 실제 답변은 별도 미수신이다. |
| 파일 인수와 운영 기록 | 공개 응답 파일의 크기·해시와 실행 조건·선택 자료를 연결했다. 비공개 입력 ZIP은 발신 사본과 11개 항목 검수까지 확인했다. | 생성 당시 전체 입력·전송 기록과 같은 운영 DB의 재시작 전후 원자료는 미수신이다. ZIP은 승인 전달 경로·수신 범위와 상대의 실제 파일 수신증이 없어 수신 완료로 처리하지 않았다. |

설명서와 제조사 FAQ는 제품 기능·사용 조건의 근거다. 고객의 실제 불편이나 수요는 실제 후기·사용 Q&A와 함께 확인해야 하며, FAQ를 고객 후기 건수에 넣지 않았다.

특히 냉장고 조건 변경 응답에는 “하드웨어를 바꾸지 않는다”는 조건과 턱을 낮추거나 제거하는 제안이 함께 남아 있었다. “이사 전까지만 쓰겠다”는 말은 앞으로의 의향으로 읽었다. 이런 대조는 원문 검수 결과이며 승인된 정답·독립 정확도 평가를 대신하지 않는다.

확인한 범위의 자료 조사와 부분 검수는 진행됐다. 자동 표·날짜·정확 구매 모델·실제 결과 인수 등 미확인 사항이 남아 있어 자료 조사 전체 완료나 고객 수요 입증으로 표시하지 않았다.
