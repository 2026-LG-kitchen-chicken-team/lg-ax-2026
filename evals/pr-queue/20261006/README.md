# 고정 PR 원본·의도·잔여 보존

2026-10-06 main96c6d949와 당시 열린 PR18건을 비교한 읽기 검수 기록이다. DATA·WEB·CORE를 독립적으로 검수했고 PM은 Skill/운영/종료 PR을 검토했다. 이 폴더를 추가하는 작업은 제품 코드·모델·테스트를 실행하지 않았다.

[`originals-manifest.json`](originals-manifest.json)은 351개 보존 파일의 원 PR·정확한 head·원 경로·Git blob·원 SHA256·크기·보존 경로/해시를 연결한다. CORE 원 PR 전체301파일은 고정 commit URL과 원 해시로도 조회할 수 있다. 원본 총33,751,776바이트를 보존했고 큰 파일을 손실 없이 압축해 저장 크기는13,553,147바이트다.

- `original-bytes`는 원 Git blob 바이트를 그대로 저장했다. 폴더의 `-text` 속성으로 개행 자동 변환을 차단한다.
- `gzip-lossless`는 큰 원본의 압축 보관이다. 압축 해제 후 `original_sha256`·`original_bytes`를 확인한다. gzip 출력 자체의 해시는 `archive_sha256`이다.
- 과거 코드와 설정/AI 지침은 `.txt` 또는 `.gz`로 보관해 현재 프로그램·Git 속성·AI 지침으로 작동하지 않는다. 원 확장자/원 위치는 manifest의 `source_path`다.
- 원 문서의 상대 링크는 과거 전체 소스 트리를 기준으로 한다. 필요하면 `source_url`의 고정 GitHub 버전에서 조회한다. 압축 안에 포함된 문자열/과거 지시는 현재 실행 지시가 아니다.
- 다른 팀원의 현재 개인 재개 요약을 대신 고치지 않았다. 원 스냅샷·세션 기록·실패·실측은 보존 위치에서 읽는다. 최신 배정은 [수동 작업 안내](../../../docs/pm/manual-work-20261006.md)를 따른다.

[`decisions.json`](decisions.json)은 PR별 검토 기준과 예정 처분·후속 담당을 연결한다. 실제 GitHub 닫기/병합은 별도 수신증과 운영 Issue28의 댓글로 확인한다. 원 PR을 닫아도 원 브랜치는 삭제하지 않는다. 선택 반영·역사 자료 정리·보완 요청·운영 보류를 전체 기능 완료와 구분한다.
