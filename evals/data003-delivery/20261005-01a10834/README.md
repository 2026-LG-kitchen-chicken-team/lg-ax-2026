# #14 개발 비교 결과·준비 자료 부분 인수

사용자 “이때까지한거 pr이슈 올려”에 따라, 이 대화의 기존 로컬 산출물과 실제 실패를 전달한다. 원 실행은 2026-10-05 06:01 KST까지 수행됐으며, 게시 준비를 위해 모델을 다시 실행하거나 평가 답안을 수정하지 않았다.

## 포함 범위

- `evals/data003-preparation`: 질문 15개·사실 요약 27개·11개 정답 근거와 4개 근거 부족 질문, 고정 검색/OCR 비교 조건. 개발용이며 독립 최종 평가가 아니다.
- `evals/data003-execution`, `evals/data003-followup`: BM25 기준선의 초기 실패·복구·원시 반복·분석 및 후속 검증.
- `evals/data003-ocr-inputs`: 원문 6페이지·14개 수동 인식 영역의 좌표/해시와 시각 검토. PDF 원본과 crop 이미지 자체는 포함하지 않는다.
- `evals/data003-live`: 고정 revision·라이선스·파일 해시, CPU 실측·원시 순위·OCR 인식·실패·조건·패키지 freeze·검사 기록. 검색 225회와 OCR 70회의 측정 결과를 보존한다.
- `evals/data004-preparation`: 후속 #15 검수 기준 10개·개발용 12사례·빈 검수표. 실제 독립 평가·실제 고객 리뷰·제조사 개정의 증거가 아니다.
- 이 폴더의 `original-work-log.md`, `original-evidence.md`: 기존 작업 공간의 개인 기록 원문 스냅샷. 역사 기록은 작성 당시 범위이며 최신 팀 전체 상태를 대신하지 않는다.
- `source-review.patch`, `source-review.json`: 새로운 benchmark/준비/검증 코드 10개와 테스트 2개의 원래 경로·원본 bytes·SHA-256을 보존한 **검토용 자료**. 실제 실행에 사용한 버전은 각 실측 폴더의 `runner-source.py` 및 기록된 hash를 우선한다. `historical-model-benchmark.py.txt`는 원 실행의 기존 BM25 의존 소스다.

## 실측과 해석

| 방법 | 첫 근거 적중 | 질의 중앙값 |
|---|---:|---:|
| BM25 | 10/11 | 0.634 ms |
| BGE-M3 | 11/11 | 316.221 ms |
| BGE-M3 + 재정렬 | 11/11 | 6006.497 ms |

BM25가 놓친 MW-01을 두 공개 모델이 회복했다. 이 작은 개발셋에서는 재정렬이 첫 근거 적중을 추가로 개선하지 않았다. 모델 로딩·인덱스 생성은 질의 시간과 별도로 기록했다. 4개 근거 부족 질문의 최종 의미 답변은 평가하지 않았다.

OCR은 14영역×5회, 오류 0회다. 문자 완전 일치 8/14·micro CER 6.87%, 숫자 본값 15/15·명시 단위 12/12, 엄격 숫자 필드 전체 일치 10/11이다. `1000 W*1` 대 `1000 W∗1`의 각주 기호 차이와 공백 누락을 그대로 유지했다. 표의 제품 열/레이아웃 자동 인식 정확도는 미측정이며, 수동 crop을 자동 표 인식 성능으로 사용하지 않는다. PDF 텍스트의 14구절 존재 검사는 OCR CER와 다른 검사다.

원 검증은 준비 188·후속 164·실측 216항목 PASS였다. 원 전체 시험 492개에서는 Windows CI helper cleanup 1개가 실패했고 관련 7개 단독 재검사만 통과했다. 전체 성공으로 정정하지 않는다. 게시 시점에 별도 source copy·고정 Docker image·network=none·zero-auth 조건의 관련 17개 테스트가 통과했다. 기존 모델 비교나 전체 최신 main을 다시 실행한 것은 아니다.

## 원래 경로의 코드가 아직 적용되지 않은 이유

최신 중앙 정책은 `scripts/` 전체를 `sensitive operating paths require manual PM work`로 거절했다(422). 정책을 변경하거나 코드의 활성 위치를 옮겨 우회하지 않았다. 승인된 산출물·불변 기록 경로만 중앙 예약하고, 원래 경로가 표시된 패치와 정확한 소스 스냅샷을 검토 자료로 전달한다. **이 PR은 12개 코드/테스트를 실제 `scripts/`, `tests/`에 설치하지 않는다.** 원래 경로에 대한 PM 수동 인수·검토 후 별도의 실제 코드 반영이 필요하다.
