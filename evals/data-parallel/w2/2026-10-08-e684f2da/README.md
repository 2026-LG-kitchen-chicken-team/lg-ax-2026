# 제품 자료와 후기 통계 검수 결과

냉장고·식기세척기·전자레인지 자료가 어떤 모델·판본·후기에 연결되는지 대조하고, **기존 238건과 개발용 141행을 보존한 채** 통계를 검수했다. 원래 확보한 설명서 3개와 추가 15모델 후보를 재사용했다. 이 문서는 이번 검수 결과이며 기존 자료의 새 승인·운영 등록을 뜻하지 않는다.

## 새 사용 글의 적용 범위

[ML32WW1 사용 글 원문](https://home-house-realestate.tistory.com/entry/LG-%EB%94%94%EC%98%A4%EC%8A%A4-%EA%B4%91%ED%8C%8C%EC%98%A4%EB%B8%90-%EC%84%A0%ED%83%9D-%EC%9D%B4%EC%9C%A0%EC%99%80-%EC%8B%A4%EC%A0%9C-%EC%82%AC%EC%9A%A9-%ED%9B%84%EA%B8%B0)은 오븐·구이·에어프라이 사용과 조리 도중 전자레인지 사용을 기다려야 했던 경험을 보고한다. 사용하지 않았다는 모드를 기능 부재로 바꾸지 않는다. 게시/수정 구조화 값은 모두 2024-07-20이다. 현재 인수한 설명서 MFL68822502 Rev.25_090425는 2025년 판본이라 이 글이 사용한 2024년 판본으로 연결할 수 없다. 구매 SKU는 작성자가 적은 모델과 별개로 미확인이다.

[Z330MEEF11 글 원문](https://oizzio.tistory.com/25)은 자기 사용을 주장하지만 제휴 광고가 명시돼 있다. 화면 날짜와 datePublished는 2025-09-19, dateModified는 2026-08-15다. 현재 원문을 최초 게시 당시의 동일한 내용으로 취급하지 않으며, 개인 구매·실사용·설치 조건은 확인되지 않아 보류했다.

두 원문은 공개 페이지에서 새로 확인한 **승인 전 후보**다. 본문 전체·작성자 개인정보·사진·원 HTML은 PR에 옮기지 않았다. 원 URL·원 ID·날짜 필드·응답 entity와 본문 SHA·조건 위치만 공개한다. 새 날짜 2건은 후보의 게시일 근거이며 기존 141행의 게시일을 채우는 자료가 아니다.

## 공식 자료의 조건

- LG T876MEE1H1은 870L/프리스탠딩/깊이 918mm, 삼성 RM70F63R231은 640L/KitchenFit Max/뒷손잡이 포함 697mm·제외 683mm다. 깊이의 범위·설치 형태·용량이 다르고 내부 팔 도달 거리나 같은 조건의 실측은 없다. 더 얕다는 이유로 수납 접근이나 청소 개선 효과를 확정하지 않는다.
- Z330MEEF11의 공용 설명서에서 10cm와 2.5cm는 측정 대상이 다르다. 센서 관련 설명과 설치 조건을 분리하며, 개별 현장·정확 SKU의 센서 유무는 미확인이다.
- ML32WW1의 공용 ML32 설명서에서 빌트인 예외와 장식문 경고, 통신 로고·2.4GHz·앱 버전 조건을 유지한다. 모든 ML32 모델의 선택 기능과 구매 당시 판본으로 전이하지 않는다.
- 개별 질문 470877의 600mm·590mm·조건부 567–600mm와 배관/설치 엔지니어 조건은 기존 원답변 검수를 재사용했다. 질문의 119–120mm 의미·개별 설치 가능 여부는 미확인이다. Q&A 작성일과 제조사 FAQ 날짜를 고객 후기 게시일이나 불편 분모로 세지 않는다.

## 통계 해석

239 관측→중복1 제외→238 고유 자료→개발141 선택(다른 분할97 제외)→게시일 미상141 제외→시간 분모0 순서다. **97과141은 다른 단계의 제외 수**다. 기간 필터 뒤 중복0과 원 관측 중복1도 계산 단계가 다르다.

기존 주제 초안의 종합 의견 수는 긍정106/부정13/혼합16/불확실3/중립3으로 원 membership과 일치한다. 이는 원 초안의 계산 대조이고 승인된 소비자 비율이 아니다. 110행은 여러 주제에 속하며 2개의 ‘주제·후기’ 조합은 긍정과 불편을 함께 갖는다. 주제 수를 더해 전체 후기 분모로 쓰지 않는다.

기존 59개 추가 레코드는 document_version 대신 manual_version을 가진다. 원문에 없던 필드를 채우지 않고 명시 판본 null과 기존 참조 판본을 따로 보존하여 동일 ID의 source/membership을 대조했다.

## 검증·인수

이번 오프라인 원문/metadata/membership 검수는 117항목·인용 위치292개가 일치했다. 이는 자료 연결과 산술 검증이며 주제 의미 정답·모델 정확도·시장 수요·운영 채택의 승인 근거가 아니다. 원4741 tracked 파일의 SHA를 보존했다. 모델/OCR·기존 수집·225회 실험·11문항 재채점·운영 API/DB·서버·메일·CI 재실행은 하지 않았다. 자동화 OFF다.

첫 후보 HTML 추출기의 요소 깊이 처리로 일부 본문이 누락됐다. 원 응답과 실패를 보존하고 같은 HTML을 오프라인으로 재파싱하여 7조건 위치를 확인했다. 새 원문 요청은 하지 않았다. 첫 통계 검수기의 선택 필드 2오류도 원 코드·실패를 보존하고 실제 원자료의 필드 차이를 반영해 수정했다.
