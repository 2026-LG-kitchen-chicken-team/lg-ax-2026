# OCR 입력 준비와 PDF 텍스트 추출

설명서6페이지/6사례의 줄·수치 영역14개를 300DPI/RGB로 생성했다. 좌표·원문 해시·crop 해시를 고정한다.
원문 페이지 이미지·전체 추출 텍스트·crop 이미지는 private에 있고 이 폴더에는 메타데이터만 있다.

crop-manifest.json: 영역/정답/좌표·이미지 크기·hash와 시각 검토 상태.
text-extraction-comparison.json: pypdf 실제 추출에서 짧은 정답 구절의 존재를 대조한 결과.
구절 존재는 CER/숫자·단위·모델 열 정확도가 아니다. 이 점수들은 미측정 null로 둔다.
동일 숫자가 다른 열에도 있는 DUE 외형/MW 가용용량은 원문 열의 좌표를 수동으로 고정했다.
MW 외형 치수의 mm 단위는 값 crop 밖 표 머리글에 있어 context 이미지에 보존했다.
수동 영역 선택·PDF 텍스트 추출은 Paddle 인식이나 전체 페이지 탐지/레이아웃 평가가 아니다.
다음은 crop 시각 검토 기록 후 기존 인식 모델 환경을 확인하여 별도 폴더에서 실제 인식·숫자 연결을 비교한다.

시각 검토 완료: visual-review.json에서 crop14개와 원문6페이지를 대조했고 줄 혼입을 수정했다. 이 검토는 Codex의 입력 검토이며 PM 검수나 실제 인식 성능이 아니다.
