# 수동 품질 R1 개발 입력

PM의 원 [여섯 실행 입력](../../../pm-intake/20261006/core/cases)과 합성 제품·리뷰·설명서를 보존하고 자료 버전 `0.1.0-manual-quality-r1-development`를 분리했다. 원 제품/모델/문서 버전·기능·출처 ID·locator·리뷰/설명서 원문은 그대로다. 실제 LG 제품 사양·고객 수요 증거가 아니다.

식기세척기 normal/changed는 신청 사례의 **적재·배치 안내**로 요청 상황과 작업을 정렬했다. changed의 사용자 확인 조건도 배치 안내에 맞춘 AI 개발 변형이다. 이를 사용자가 실제로 새 조건을 확정한 회차로 기록하지 않는다. 이전 코스 선택 입력·실패·모델 비용은 원 위치에 보존한다. 냉장고/전자레인지 요청과 조건 변경은 자료 버전 외에 유지했다.

[provenance.json](provenance.json)에 원/새 파일 SHA와 변경 필드가 있다. `validate_inputs.py`는 입력 계약·모델/버전/근거 연결·원본 보존만 검사하며 모델을 호출하지 않는다. 출력 정답을 제공하지 않고 독립 평가의 정답을 읽거나 프롬프트 수정에 쓰지 않았다.

격리 환경에서 `python evals/core-manual-quality/20261006/development/validate_inputs.py`로 검사한다. 실제 Qwen3:8b 정상/조건 변경 검증과 같은 Qwen3.5:27B 문제 1건 재검증은 별도 원 호출/응답·모델 고정 설정·최종 상태·실패·비용으로 제출해야 한다. 입력 준비나 fixture 검사 통과는 해당 실모델 검증을 대신하지 않는다.
